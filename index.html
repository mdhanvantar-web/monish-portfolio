01 — About

Curious by nature.
Builder by instinct.

I learn by building. Every project starts as a question — how does this work, and can I make it real?

I'm Monish Dhanvantar Sambangi, a B.Tech Cyber Security student at Baba Institute of Technology and Sciences (2025–2029), and an emerging game developer. My strongest work lives in gameplay systems — from a browser-based 3D arena shooter with wave modifiers and generative audio, to desktop games written from scratch in Java.

Games are my primary craft, but the curiosity doesn't stop there. I build web applications, explore AI and data, and approach security problems with an engineer's mindset. Different disciplines, one instinct: turn ideas into working systems.

I care about the parts nobody sees — the game loop, the collision logic, the architecture decisions — because that's what makes the parts everybody sees feel right.
